# 利用上の注意

## 勤務案の位置付け

本ソフトウェアが生成又は比較する勤務案は、確認作業を支援する候補であり、人事・労務上の最終決定ではない。公開前に、導入機関が雇用契約、就業規則、労使協定、資格、必要配置、休暇、兼業、健康確保措置その他の適用条件を照合すること。

最適化の結果は、入力された候補、制約及び目的関数の範囲に限られる。入力漏れ、未確認の原本、制度の解釈又は運用上の例外を自動的に補うものではない。違反件数が少ない案又は目的値が良い案が、必ずしも現場にとって最良であるとは限らない。

## 適用範囲

厚生労働省の「いわゆる『シフト制』により就業する労働者の適切な雇用管理を行うための留意事項」は、勤務日又は勤務時間を一定期間ごとに組む働き方を対象として説明し、固定的な三交替勤務等をその定義から除いている。本ソフトウェアが全ての勤務形態について法令適合を自動判定するとは扱わない。

職員勤務情報だけを扱う合成環境について、医療情報システムとしての適合認定は行っていない。患者情報その他の医療情報を扱う構成へ変更する場合は、導入機関が適用範囲と追加措置を確認すること。

## 確認済み範囲

自動試験は、記録された合成条件での動作を確認するものである。30名の利用者評価、VoiceOver/NVDA実機評価及び実運用相当の75パーセンタイル性能測定が完了するまでは、「使いやすい」「WCAG適合」「本番利用可能」又は「安全性を証明済み」と表現しない。`IDEAL_UI`の既定値はOFFである。
