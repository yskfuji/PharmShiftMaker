# 利用上の注意

本書は、本ソフトウェアが作成する勤務案の位置付け、適用範囲及び確認済みの範囲について、利用者が留意すべき事項を定める。

## 1. 勤務案の位置付け

1. 本ソフトウェアが生成し、又は比較する勤務案は、確認作業を支援する候補であり、人事・労務上の最終決定ではない。
2. 導入施設は、勤務案を公開する前に、雇用契約、就業規則、労使協定、資格、必要配置、休暇、兼業、健康確保措置その他の適用条件を照合すること。
3. 最適化の結果は、入力された候補、制約及び目的関数の範囲に限られる。本ソフトウェアは、入力の漏れ、未確認の原本、制度の解釈又は運用上の例外を自動的に補うものではない。
4. 違反の件数が少ない案又は目的関数の値が良い案が、必ずしも現場にとって最良であるとは限らない。

## 2. 適用範囲

1. 厚生労働省の「いわゆる『シフト制』により就業する労働者の適切な雇用管理を行うための留意事項」は、勤務日又は勤務時間を一定期間ごとに組む働き方を対象として説明しており、固定的な三交替勤務等をその定義から除いている。本ソフトウェアが、全ての勤務形態について法令への適合を自動的に判定するものとは扱わない。
2. 職員の勤務情報だけを扱う合成環境について、医療情報システムとしての適合の認定は行っていない。患者情報その他の医療情報を扱う構成に変更する場合は、導入施設が、適用範囲及び追加の措置を確認すること。

## 3. 確認済みの範囲

1. 自動テストは、記録された合成条件での動作を確認するものである。
2. 次の評価が完了するまでは、「使いやすい」「WCAG に適合」「本番で利用可能」又は「安全性を証明済み」とは表現しない。\
   （1）30名の利用者評価\
   （2）VoiceOver 及び NVDA による実機評価\
   （3）実運用相当の環境における、75パーセンタイルによる性能測定
3. 機能フラグ `IDEAL_UI` の既定値は、無効（OFF）である。
