# 導入施設が確認すべき事項

本書は、本ソフトウェアを導入し運用する施設（以下「導入施設」といいます。）が、導入前に確認し文書化すべき一般的な事項を示すものです。

> **注記** 本書は一般的な確認事項であり、導入施設の規程又は法律の専門家の判断に代わるものではありません。

導入施設は、導入前に、少なくとも次の事項を文書化するものとします。

## 1. 利用目的及び取扱いの範囲

1. 取り扱う職員情報及び勤務情報の項目、利用目的並びに利用者を、具体的に定めます。
2. 患者情報を取り込まない構成を既定とします。医療情報を扱う場合は、厚生労働省「医療情報システムの安全管理に関するガイドライン 第7.0版」の適用範囲を確認し、必要な追加の措置を講じます。
3. 開発、研修、画面の収録及び不具合の報告には、合成データを用います。

## 2. 権限及び本人への対応

1. 職務に必要な範囲で役割と施設・部署を割り当て、定期的に棚卸しします。
2. 次の操作を禁止するサーバー側の制御が、導入した構成でも有効であることを確認します。\
   （1）管理者が自身の所属を無効にすること\
   （2）最後の管理者を無効にすること\
   （3）自身が関与する案件を最終承認すること
3. 開示、訂正、利用停止等の窓口、本人確認の方法、判断者及び記録の方法を定めます。

## 3. 保存、委託、消去及び復旧

1. 情報の種類ごとに、保存期間、法的な保全、バックアップの保持期間及び消去の時期を定めます。
2. クラウド、保守、認証、通知その他の委託先について、取扱いの範囲、安全管理措置、再委託及び契約終了時の返却・消去を確認します。
3. 消去した後に、復旧又は再取込みによって本人の情報が復活しないことを、隔離した環境で定期的に確認します。
4. バックアップの完全性、復元先の隔離、消去制御の再適用及び業務再開の承認の手順を定めます。Web 画面からは復元の操作を行わないものとします。

## 4. 安全管理及び事故への対応

1. 認証、通信の保護、端末の管理、ログの保護、秘密情報の管理、脆弱性への対応及び時刻の同期を、導入環境に合わせて定めます。
2. 漏えい、滅失又は毀損のおそれがある場合の連絡、封じ込め、調査、本人及び監督機関への対応並びに再発防止を定めます。
3. 監査ログに本人の情報を過剰に記録せず、閲覧の権限及び保存期間を管理します。
