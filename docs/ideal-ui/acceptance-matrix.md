「未完了」は合格ではない。人による評価、支援技術による評価及び実運用環境での性能の各行が合格するまで、本番採用の判定基準は満たされない。ソースコードの公開は、別の判定基準による。この判定基準は、自動検査、リリースについての最終の第三者的レビュー及び公開用出力そのものの監査を要求する。併せて、`IDEAL_UI`の既定値は無効（OFF）のままとする。

## 合格基準の統計的な限界

人による評価の合格基準は、少数例に基づく形成的評価の基準である。基準を満たしても、次の不確かさが残る。

- 30名で重大な誤確定が0件であっても、参加者単位の真の発生割合の95%信頼区間（Wilson法）は0〜11.4%である。
- 役割ごとに10名中9名が独力で完了した場合、完了割合の95%信頼区間（Wilson法）は59.6〜98.2%である。10名全員が完了した場合は72.2〜100%である。
- 非劣性の基準（完了者が1名を超えて減らない、所要時間の中央値が15%を超えて悪化しない）は、検出力を算定していない記述的な許容基準であり、統計的な非劣性の検証ではない。
- 自動試験の合格件数は、無作為に抽出した標本ではない。故障率又は信頼性の推定値として解釈しない。
