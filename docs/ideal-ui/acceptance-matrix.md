“Pending” is not a pass, and neither is a result recorded before the 2026-10-05
restructuring: such a row describes an earlier source, and the rows say which
results were re-run on the final source. A passing automated row is also not a
statement about how a screen looks to a person: on 2026-10-06 the owner of the
product reported screens that looked unstyled although every audit of the third
run was without a finding (`verification.md`). The production-adoption gate remains closed until the
human, assistive-technology and field-performance rows pass. Source-code
publication is a separate gate: it requires the automated checks, final
independent release review and exact public-export audit, while retaining
`IDEAL_UI` OFF by default. At the time of this record one automated check of
the fourth formal run, `npm audit`, fails.
