## 2. 判定の扱い

「未実施」は合格ではない。本番採用は、人、支援技術及び実地性能の行が合格するまで認めない。

ソースコードの公開は、別の判定とする。ソースコードの公開には、自動検証、最終の独立リリースレビュー及び公開用の書き出しそのものの監査を要する。ソースコードの公開に当たっては、機能フラグ `IDEAL_UI` の既定値を無効のまま維持する。
