# PharmShiftMaker

PharmShiftMaker は、病院薬剤部の勤務計画、当日の変更、休暇・勤務交換、職員に関する手続及び監査の記録を扱う試作ソフトウェアである。確認済みの契約、資格及び必要配置から勤務案を作成し、その編集、検証、確認及び公開を版として記録する。

> **重要** 本ソフトウェアについて、本番環境で利用できること、安全性が証明されていること、WCAG に適合していること及び使いやすいことは主張しない。給与計算、人事の原本の決定及び法令との最終的な照合は、導入施設又は外部のシステムが行う。30人の利用者評価、VoiceOver 及び NVDA による実機確認並びに実運用に近い性能測定は、完了していない。

## 1. 主な機能

本ソフトウェアは、次の8つの入口から利用する。

| 入口 | 内容 |
|---|---|
| 今日 | 判断が必要な事項、欠員、公開の準備、本人への通知 |
| 勤務表 | 月間の勤務、日別の表示、版の差分、本人用の出力 |
| 計画 | 前提の確認、候補の作成、案の比較、確認・編集、公開 |
| 当日運用 | 当日の予定、欠勤・交換、代わりの候補、承認、通知 |
| 申請 | 本人の申請、休暇、勤務交換、兼業・外部勤務 |
| 職員 | 職員の一覧、本人のアカウント、契約・資格、入職及び退職 |
| ガバナンス | 監査、実績の照合、本人からの請求、復旧の状態 |
| 設定 | 外観、通知、欠勤時の同意、フレックスタイム |

## 2. データの取扱い

1. 本リポジトリに収録している人物は、公開のテスト用に作成した合成データである。導入する場合は、導入施設が管理する情報に置き換える。
2. 自動テストの結果は、記録した合成条件での確認に限られる。
